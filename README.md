# Türk Masalları Derlemesi

Bu proje, Programlamaya Giriş dersi kapsamında hazırlanmış, sekiz Türk masalını dijital kitap formatında sunan etkileşimli bir web sayfasıdır.

HTML, CSS ve JavaScript kullanılarak geliştirilmiştir.

## Projenin Özellikleri

- Masallar arasında sayfa çevirerek gezinme
- İçindekiler bölümünden masal seçme
- Masalların özetlerini ve illüstrasyonlarını görüntüleme
- Masalların tam metinlerini okuma
- Yazı boyutunu büyütme ve küçültme
- Mobil ekranlara uyumlu tasarım

## Dijital Kitabı Görüntüle

https://lifozd.github.io/turk-masallari-derlemesi/Turk-Masallari/

## Kullanım

Web sayfasını açmak için `index.html` dosyasını bir internet tarayıcısında çalıştırın. Görsellerin görüntülenebilmesi için `gorseller` klasörü HTML dosyasıyla aynı konumda bulunmalıdır.
